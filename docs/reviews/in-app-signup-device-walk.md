## W4 report, 2026-10-27, and what it was

**Reported:** sign-up with an existing address and a valid password went through; a verification mail reached Mailhog "addressed to walk-creator-a".
**Found:** the address that went through was `walk-creator-a@cataylst.local` (a transposition: _cataylst_), not the seeded `walk-creator-a@catalyst.local`. It was a new address, so a **new** account (user 28, creator, unverified) was correctly created and
one mail was sent to the typo'd address; Mailhog holds exactly that one message. The seeded account (user 17) is untouched: still verified (2026-10-21), no second row for its address, no mail sent to it, and it signed in
afterwards with its old password. Replayed from the LAN with the app's origin (`capacitor://localhost`), the stored address, upper-case and space-padded variants all answer the 422 "already exists"; nothing is created.
The app sends the field exactly as typed (`email: form.email`), so it did not alter the address. **No defect; nothing in the product changed.** A spec now pins the invariant (SignUpTest, the "taken address" and "one letter different" cases).
**Left in the dev DB:** user 28, `walk-creator-a@cataylst.local`, unverified: usable as the **W10** account (sign in, do not verify). Delete it with the other walk accounts.
**Re-walk:** W4 part 3 only (the taken address, typed exactly). W5 already ran for real on the typo'd account (pending sheet, mail delivered).

**W8 report, 2026-10-28: FAIL, fixed.** Wizard account menu → Security → back arrow landed on the creator dashboard ("Your application", 0%), not the wizard step. Cause: the shell's back arrow only unwound history when the previous entry was a creator-shell page; a wizard step has the `onboarding` layout, so it fell to the dashboard. Now history is used when the previous entry is a creator page OR an `onboarding.*` route; with no usable history an incomplete creator goes to the wizard's current step (`next_step`), anyone else to the dashboard. Also: the dashboard's "Continue your application" card (incomplete only) is now a link to that same current step. **Re-check W8, then W9-W14.** Not covered by a unit spec: the look of the tappable card (chevron, no underline) and the Playwright path.
