## 3. Known limits (not failures)

- Search exists on the **agency web inbox only** (the unified inbox, which also needs `messages_v2_inbox_enabled`). The creator app has no message search in this stage, so no item above tests it.
- A message already sent is not recalled from a **push notification** that was delivered earlier: the notification text stays on the lock screen until dismissed. W9 is about the badge, not the notification text.
- An attachment of a deleted message stays stored (the delete dialog says so); it is only hidden from both sides.
