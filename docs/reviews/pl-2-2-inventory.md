## 3. Existing patterns: wide table, pinned column, horizontal scroll, narrow width

- **No table in the main app has a pinned (sticky) column.** `position: sticky` appears only in `CreatorDetailPage.vue`, `OnboardingLayout.vue`, `AnimatedWizardChromeMobile.vue` and `BoardCardDrawer.vue` (headers and footers, never a table column). The matrix is the first.
- Sideways scroll exists in three places: `BoardColumns.vue` (the board scroller, `overflow-x: auto`, a pseudo-column inside the scroller on purpose), `StrategyStepper.vue` (scrolls inside its own bar, `min-width: max-content`, switches to shared width at 1100 px) and `PersonasStep.vue` (market bar scrolls). The PL-2.1 rule applies: **the page never scrolls sideways; the wide thing scrolls inside its own container.**
- Tables elsewhere (`v-table` / `<table>` in 10 pages: roster, brands, campaigns, agency users, files, pools, bulk invite …) are ordinary and none is a grid of editable cells.
- Narrow behaviour in PL-2.1: stepper and market tabs scroll inside their bars, dialogs open fullscreen below the narrow breakpoint, three-dot menus open above. The matrix has no design at 390 px; the plan names the assumptions (§4.3).
- Menus inside dialogs use `MENU_PROPS` (z-index 2500, `strategy-menu` class); a popover on the matrix page is not inside a dialog and needs only the normal stack.

## 4. Erasure, audit, tenancy for the new table

- **Erasure.** `ErasureRegistry` has one `TableRule` per table (`wave_usps`, `wave_personas`, `wave_persona_angles` are `NotApplicable`, agency-authored, no user column). A test fails for a table with no rule. The new table needs a rule in the same commit: `NotApplicable`, agency-authored free text (rationale, message line), no user column (plan §1.5).
- **Audit.** `AuditAction` enum has 4 `wave_usp.*` and 7 `wave_persona*.*` cases (lines 538 to 552); `AuditActionEnumTest` holds the catalogue as a literal list (lines 228 onward). A new action is added to both in the same commit, each with its Erasure decision. Audit rows carry ids, counts and field names, never the text.
- **Tenancy.** `docs/security/tenancy.md` lists routes; the PL-2.1 strategy routes use `auth:web + tenancy.agency + tenancy`, `{usp}` and `{persona}` ulids are looked up **through the wave** (404 otherwise), the model uses `BelongsToAgency`. The new table has `agency_id` and the same.
- **Flags.** `StrategyEnabled::active()` = `waves_enabled` and `strategy_enabled`; every endpoint's first line. Pennant scope `__laravel_null` (global).
